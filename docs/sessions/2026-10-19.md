## Implementation

- Reused Yahoo's persisted league/settings/team models and existing player and
  roster import. No new persistence model, migration, data source, or
  calculation service was added.
- Extended league reads with persisted league/settings import timestamps.
- Extended `GET /api/v1/rosters` to report every persisted team, including
  teams with no roster import, plus Yahoo source, snapshot timestamp, and an
  explicit state:
  - `not_imported`: there is no persisted roster snapshot.
  - `stale`: league/team/settings data was refreshed after the roster snapshot.
  - `available`: the roster snapshot is not known to predate those imports.
- Added the home-page Championship HQ foundation panel. It displays persisted
  Yahoo scoring/roster settings and team rosters, and offers an explicit refresh
  that imports league state before players/rosters. Missing rosters are not
  presented as empty; valid empty snapshots are explained.
- Snapshot age is shown without an age-based stale cutoff. Matchup and
  transaction context are unavailable. This first panel did not calculate
  categories, projections, or recommendations.

## Category + Team Identity Baseline

- Added database-only `GET /api/v1/team-category-baseline?league_key=...`.
  It reads persisted Yahoo settings/teams/rosters, player identity mappings,
  and NBA season-stat rows; it does not call Yahoo or NBA providers.
- Category identifiers/names are resolved against an explicit supported set.
  Unsupported categories return `unsupported` with no fabricated value.
  Supported categories return `available`, `partial`, or `unavailable`, raw
  results, contributing and missing/unmapped player counts, missing player
  reasons, the selected season/stat type, and source import timestamps.
- The source is the latest eligible regular-season NBA stat season with
  mapped rostered-player stats, no later than the Yahoo league season when
  known. This is not an intersection across all roster players; a player
  without a selected-season row stays missing rather than falling back to an
  older season. Counting categories sum persisted NBA per-game values; FG% and
  FT% use season makes divided by season attempts, derived from per-game
  components × games played. Missing required components and zero aggregate
  denominators produce no percentage value. Yahoo scoring modifiers do not
  alter raw category output.
- Added a minimal Championship HQ Team Identity panel. It labels results as a
  roster baseline (not a projection, league percentile, matchup advantage,
  recommendation, or championship probability) and displays roster coverage,
  missing player names/reasons, category status, and source timestamps.
- Validation: 5 backend tests passed on a newly created disposable PostgreSQL
  container (including 2 category tests for recognition, count aggregation,
  weighted percentages, missing denominator, unsupported category,
  partial mapping, empty/not-imported rosters, and guarded database-only reads,
  plus player-read API and draft-readiness regressions). All 24 frontend tests
  passed, including the focused rendering test; strict
  TypeScript/Vite production build passed in a disposable Node container.
  Existing Starlette/httpx deprecation warning only. No production database,
  Yahoo request, or NBA provider call was used.
